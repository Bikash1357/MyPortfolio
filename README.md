# Bikash Kumar Thakur — Portfolio

Personal portfolio built with **Next.js 16, React 19 and Tailwind CSS v4**. Black & white theme with a light/dark toggle.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content

All text (profile, skills, experience, projects, education) lives in [`data/resume.ts`](data/resume.ts).

Before deploying:
- Add your resume PDF as `public/resume.pdf` (the "Resume" and "Download CV" buttons link to it).

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Go to [vercel.com/new](https://vercel.com/new), import the repo, and click **Deploy**. Vercel detects Next.js on its own, so no settings are needed.

Or from the terminal: `npx vercel` (then `npx vercel --prod`).
